# UrbanSense AI Flutter Frontend - Complete (Soothing UI)

This is the ultimate, fully-featured Flutter frontend for UrbanSense AI with a completely redesigned, visually soothing interface.

## New Features
- **Soothing UI:** Calm colors (Teal, Mint, Soft Grey), highly rounded corners, and soft drop shadows to create a stress-free citizen portal experience.
- **Admin Console:** Added `AdminScreen` to manage, review, and resolve user complaints dynamically.
- **Advanced Analytics:** Added `AnalyticsScreen` displaying visual resolution metrics and platform health.
- **Feedback System:** Added `FeedbackScreen` allowing users to rate their app experience using stars and text reviews.
- **Slide-out Drawer:** Integrated a beautiful hidden navigation drawer inside the Home Screen for Administrative and Auxiliary tools without cluttering the main Citizen Bottom Navigation bar.
